- [Verify](https://docs.figment.io/reference/post_x402-verify.md): Protocol-level rejections return HTTP 200 with `{isValid:false}`. Only malformed envelopes return 4xx. Scheme-specific payload shape is enforced by the registered scheme, not at the HTTP layer.
- [Settle](https://docs.figment.io/reference/post_x402-settle.md): Screens payer + payee, reserves a dedup key, broadcasts the transaction, and records the settlement. Protocol-level failures return HTTP 200 with `{success:false, errorReason}`.
- [Partner Analytics](https://docs.figment.io/reference/get_x402-partner-analytics.md): Returns settlement counts and USDC volume grouped by merchant + endpoint for the partner org identified. This is a Figment-added endpoint, so responses use the `{data, meta}` envelope, not a bare protocol body.
- [Settlement Reports](https://docs.figment.io/reference/get_x402-settlement-reports.md): Pull your organization's settled payments as a daily rollup, grouped by buyer, merchant address, network, and token.
